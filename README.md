# TechTools — Ad Demo Website

A simple responsive website made for demonstrating how website advertising works.

## Run it

### Option 1 — easiest
Double-click `index.html` and open it in your browser.

### Option 2 — local server
If you have Python installed:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000

## Add real ads

There are three clearly marked ad areas in `index.html`:

- TOP AD
- MIDDLE AD
- BOTTOM AD

For Adsterra, create an ad unit in your publisher dashboard and paste the provided code into one of these areas.

For Google AdSense, after your site is approved and you create an ad unit, paste the AdSense-provided code into the relevant area.

Do not use fake ad code or click your own ads. Follow each network's publisher policies.
